# Evaluation results

Offline evaluation runners write generated output below this directory. Those
ordinary run directories are ignored by default.

The intentionally version-controlled evidence is in
[`published/`](published/). It contains curated Paper B trial rows, aggregate
summaries, frozen inputs and configurations, provenance ledgers, validation
notes, and checksums. Replayable program fixtures remain separately under
[`tests/acceptance/`](../../tests/acceptance/). Root `results/`
is reserved for locally generated runtime-agent records and logs.
