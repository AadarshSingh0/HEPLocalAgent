## Structured-analysis repair contract

When repairing `analysis`, obey all of the following rules.

1. Return the complete `WorkflowIntent` JSON object. Do not return a
   partial patch, explanation, Markdown, comments, or MA5 commands.

2. Preserve every explicit value from the user request unless a
   validator message requires changing it. In particular, preserve:
   - collider energy;
   - event count;
   - particle identities;
   - histogram observable;
   - histogram bin count;
   - histogram minimum and maximum;
   - explicitly supplied cut values.

3. Never invent numerical values.
   - If the user says only "standard cuts" without numerical
     thresholds, use `"cuts": []`.
   - Do not assume common values such as 20 GeV, 25 GeV, 2.4, or 2.5.
   - A vague request is not permission to add inferred cut values.

4. Explicit custom plotting requests require a non-null `analysis`
   object containing the requested histogram. Do not replace an
   explicit histogram request with `analysis: null` or quick-look mode.

5. Every analysis object reference must use this structure:

   `{"particle": "<particle>", "rank": 1}`

6. Observable object arity is strict:

   Exactly zero object references:
   - `met`

   Exactly one object reference:
   - `pt`
   - `eta`
   - `abs_eta`
   - `phi`
   - `energy`

   Exactly two object references:
   - `invariant_mass`
   - `delta_r`
   - `delta_phi`

7. Examples of valid object lists:

   Electron transverse momentum:

   `"objects": [{"particle": "e-", "rank": 1}]`

   Positron transverse momentum:

   `"objects": [{"particle": "e+", "rank": 1}]`

   Electron-positron invariant mass:

   `"objects": [
       {"particle": "e+", "rank": 1},
       {"particle": "e-", "rank": 1}
   ]`

8. Use appropriate units:
   - `GeV` for `pt`, `energy`, `invariant_mass`, and `met`;
   - `dimensionless` for `eta`, `abs_eta`, `phi`, `delta_r`,
     and `delta_phi`.

9. A user instruction such as:

   `plot invariant mass from 50 to 130 GeV with 40 bins and apply
   standard cuts`

   must be represented as:
   - one `invariant_mass` histogram;
   - two explicit object references;
   - 40 bins;
   - minimum 50;
   - maximum 130;
   - `"cuts": []`.

10. Read every validator issue and schema error literally. Correct all
    reported errors in the next complete JSON response rather than
    repeating the previous malformed structure.
